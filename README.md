# Superfolio website

Marketing site for [Superfolio](https://superfoliomoney.vercel.app), a personal-finance web app.
The app lives in a separate repo (`isuruar/wealthtracker`); this repo never changes it.

## Status

Design direction, waiting for sign-off. Nothing is scaffolded yet.

- `design/direction.md`: reference study, direction, type, colour, motion, logo, and open decisions
- `design/mock/index.html`: hero mock (open it in a browser; the goal card is interactive). Add `?theme=dark` or `?motion=off` to the URL to preview those states.
- `design/mock/brand.html`: logo options, type scale, palette
- `design/screens/`: screenshots at desktop and phone widths, in light and dark

All figures in mocks and screenshots are made up.
